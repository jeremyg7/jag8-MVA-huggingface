# Contest materials

Checked against the live Official Rules and both submission instruction pages on 20 October 2026.

## Repository contents

| Requirement or supporting material | Included here |
|---|---|
| Documented, reproducible Track 1 code and configuration | `scripts/`, `config/`, reproduction commands in `README.md` |
| Tests | `tests/test_track1_core.py`; 28 synthetic unit/integration tests passed with bcftools 1.24 |
| Track 1 written report | `docs/jag8_track1_report.md` |
| Track 2 written report | `docs/jag8_track2_report.pdf` and `.md` |
| Optional, recommended methods descriptions | `docs/jag8_track1_methods.xlsx` and `docs/jag8_track2_methods.xlsx` |
| Track 2 report figures and document renderer | `docs/figures/`, `docs/build_report.py` |
| AI assistance disclosure | Both reports, both methods workbooks, and `README.md`; voice production is identified in `README.md` |
| Required acknowledgement and dataset citation | `README.md` and both reports; the video carries the acknowledgement ending card |

Track 2 proposes laboratory tests; it does not report completed drug experiments. Its scientific evidence is cited in the report. The document renderer uses the included Markdown and figures, without controlled-access inputs.

A fresh local Track 1 reproduction on 19 October matched the frozen shortlist and submission hashes. Controlled-access inputs and patient-derived outputs remain private; they are not distributed in this repository. Exact local storage locations must be supplied by an authorized participant when reproducing the analysis.

## Materials submitted separately

- **Track 1:** upload the prediction CSV and written report to the Track 1 form, with this repository's URL. Prediction CSVs and their private fallback are intentionally excluded from GitHub.
- **Track 2:** upload the written report to the Track 2 form, with this repository's URL and the hosted pitch-video URL.
- **Pitch video:** upload the final 2:55 MP4 to YouTube or Vimeo. Its actual URL is supplied separately in the contest form; no hosted URL was available when this repository was prepared. The MP4 is not required in GitHub.

This repository is private during preparation. The instructions require it to be made public once the hackathon ends. The reports, video upload, and contest submissions are separate actions; creating this repository does not submit either track.
